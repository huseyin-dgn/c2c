# Asset provenance

Original motherboard CPU-region meshes and routing atlases authored for this repository by scripts/bake-motherboard.mjs. No external image or mesh is embedded. Geometry authoring/export: Three.js (MIT, existing dependency); raster conversion: Sharp (Apache-2.0, existing dependency).

The layout represents socket retention, VRM phases, decoupling banks, memory connector crops and PCB routing. It is not an electrically verified board, specific commercial product, or claim that C2C manufactures hardware.

A Sketchfab candidate (Mother Board 3d Model, ARComputerFundamentals, 99a5f94e130a41c48590d59877f08663) was screened from its public listing. Its asset endpoint could not be inspected (403); no model was downloaded or reused. No third-party attribution claim is made for the original meshes here.
